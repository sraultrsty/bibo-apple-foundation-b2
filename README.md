# 🥤 Bibo

**Bibo** is a self-monitoring iOS app designed to help teenagers track their daily drink intake, especially sugary beverages. By providing visual data and clear warnings, the app empowers users to make more informed beverage choices and build healthier drinking habits.

---

## Key Features

* **Sugar Summary:** View total daily sugar consumption at a glance.
* **Intake Status Alerts:** Instantly see your health status category into three simple tiers:
*   * 🟢 **Safe:** Within healthy limits
    * 🟡 **Moderate:** Approaching the maximum ideal daily limits.
    * 🔴 **Overconsumed:** Exceeded the limits.
* **Drink History:** Keep a running log of all beverages logged throughout a day, and filter progress according to your categorized health status.

---

## Tech Stack

* **Platform:** iOS 15.0+
* **Language:** Swift
* **Framework:** SwiftUI

---

## Requirements & Installation

### Prerequisite
* **Xcode 13+** Installed from the Mac App Store

### Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Open the project:**
   Open Xcode, select **"Open an existing project"**, and navigate to the cloned folder to open `Bibo.xcodeproj`.
3. **Run the App:**
   Select your preferred iPhone simulator and press `⌘ + R` (or click the **Play** button) to build and run.
